Configure the connection to your Meilisearch server for fast, typo-tolerant search.

The URL of your Meilisearch server. Default: http://localhost:7700
The API key for your Meilisearch server. Leave empty if no authentication is required.
The name of the Meilisearch index to use. Default: jellyfin
Automatically update the search index when items are added, updated, or removed from your library.
Results with a match score below this threshold will be filtered out. Set to 0 to include all results. Default: 50
How Meilisearch handles a query it cannot match in full. Frequency discards the word that appears most often in your library, so “the matrix reloaded” keeps “reloaded”; last discards from the end instead; all trades recall for precision. Frequency needs Meilisearch 1.11 or newer and falls back to last automatically on older servers.
Maximum number of items per real-time sync flush. Default: 500
Maximum wait time in milliseconds before flushing a partial real-time sync batch. Default: 2000
Number of items per reindex push. Default: 2000
Number of concurrent batches during reindex. Default: 2
Periodically pings Meilisearch and automatically pauses real-time sync when the server is unreachable.
Interval in seconds between background health checks. Default: 60
Each line maps a term to comma-separated alternatives, e.g. movie=film,picture.

Reconnect drops the current connection and dials Meilisearch again — useful after moving or recreating the server. Transient failures recover on their own.
