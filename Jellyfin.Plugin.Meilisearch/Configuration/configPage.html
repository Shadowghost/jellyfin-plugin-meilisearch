Semantic Search

Adds meaning-based matching on top of keyword search, so “space movie with a robot” can find WALL·E. The model runs locally - no external service and no data leaves your server - but it downloads several hundred megabytes once and then costs CPU time for every indexed item. Leave it off unless you want that trade.
While this is off, nothing about embeddings is loaded or downloaded. Each model keeps its own download and its own vector cache, so switching away from one and back again costs neither - but the index has to be rebuilt after every switch, because vectors from one model mean nothing to another.
When off, run the Download Meilisearch Embedding Model scheduled task instead.
0 is pure keyword search, 100 is pure meaning. Default: 50
How much of each item's metadata is embedded. Higher is slower. Default: 256
Items per forward pass. Default: 8
0 uses half your CPU cores, leaving headroom for transcoding. Default: 0
Stores vectors at one bit per dimension instead of a 32-bit float: about 32 times smaller, which keeps them in memory instead of read from disk on every search - seconds on a cold index. The trade is some ranking precision in the vector half of a search, and what it swaps in are near-ties, within roughly 1.5% of the similarity of what they replace. Keyword matching is exact either way.

Turning it back off needs a rebuild, since Meilisearch discards the full vectors as it compresses them - but that rebuild reads from the vector cache below, which always keeps full precision, so it re-uploads rather than re-running the model.
A rebuild re-embeds the whole library, and unchanged metadata gives an identical vector - the cache turns that back into a file read instead of hours of CPU. Costs about 4 KB per item, kept under Jellyfin's data directory. Leave this on unless disk space is tight.
A rebuild already drops cached vectors it no longer needs, so the cache follows your library's size on its own. Set a limit only to cap disk use. Default: 0 (unlimited)
Leave empty to store models under Jellyfin's data directory. Each model gets its own subdirectory.
